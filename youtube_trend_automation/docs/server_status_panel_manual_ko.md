# 서버 자동 업로드 상태 패널 안내

## 무엇을 보여주나요

Studio 상단의 `서버 자동 업로드 상태` 패널은 아래 정보를 보여줍니다.

- 서버 서비스: 서버 자동 업로드 서비스의 현재 상태
- 다음 업로드: 서버 기준 다음 자동 업로드 예정 시각
- 남은 시간: 지금부터 다음 업로드까지 남은 시간
- 모니터: 다음 자동 업로드 결과 추적 상태
- 마지막 주제: 서버가 마지막으로 처리한 주제

## 버튼 설명

- `서버 상태 새로고침`
  서버에 다시 접속해서 최신 상태를 즉시 불러옵니다.

- `다음 자동 업로드 모니터 시작`
  서버에 다음 회차 감시 작업을 걸어둡니다. 다음 예약 업로드가 끝나면 서버가 결과를 자동 기록합니다.

## 어디에 기록되나요

- 서버 스케줄 상태: `data/runtime/scheduler_state.json`
- 다음 회차 모니터 결과: `data/runtime/next_run_monitor.json`

## 현재 운영 방식

- 자동 업로드는 서버만 담당합니다.
- 로컬 Windows / EXE 는 설정 변경과 수동 1회 업로드만 담당합니다.
- Studio에서 주기를 바꾸고 저장하면 서버가 다음 체크부터 새 주기를 반영합니다.
